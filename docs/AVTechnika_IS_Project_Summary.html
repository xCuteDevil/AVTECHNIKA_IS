AV Technika – IS výpůjček

Stručné informace o projektu (technologie, architektura, běh a nasazení)

Popis

Interní systém pro evidenci techniky, zákazníků, výpůjček a zakázek. Frontend umožňuje skenování QR kódů (mobil) a rychlé přidávání položek / výpůjček.

Repo a struktura

  • main.py – REST API (FastAPI)
  • models.py, migrations/ – SQLAlchemy/Alembic
  • avtechnika-dashboard/ – React/Vite frontend
  • certs/ – lokální vývojové certifikáty (necommitovat)
  • dev.db – SQLite pro vývoj

Použité technologie

Frontend: React 19 Vite 7 Tailwind CSS 4 html5-qrcode Backend: FastAPI Uvicorn SQLAlchemy 2 Pydantic v2 Alembic SQLite (dev)

Doporučená DB pro produkci: Postgres (např. Supabase/Neon). Frontend lze nasadit na Cloudflare Pages, backend na Fly.io/Render/Railway.

Architektura API

  • /health – liveness
  • /items – CRUD položek
  • /customers – CRUD zákazníků
  • /loans – výpůjčky (+/return)
  • /orders – zakázky (+/add_item_by_code, /close, /{id}/loans)

CORS povolené pro lokální dev: http(s)://localhost:5173 a LAN IP.

QR sken na mobilu

  • Pro kameru je nutný HTTPS a povolení přístupu.
  • Vývoj: doporučeno mkcert certifikáty a spuštění Vite s VITE_DEV_HTTPS=true.
  • Frontend defaultně volá API na https://HOST:8000 (přes window.location), lze přepsat VITE_API_BASE.

Jak spustit (vývoj)

Backend (HTTPS):

cd AVTECHNIKA_IS
source venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000 \
  --ssl-keyfile certs/dev.key --ssl-certfile certs/dev.crt

Frontend (LAN + HTTPS):

cd avtechnika-dashboard
VITE_DEV_HTTPS=true npm install
VITE_DEV_HTTPS=true npm run dev -- --host 0.0.0.0

Otevři na telefonu: https://<LAN_IP>:5173. Pokud je potřeba, potvrď self-signed certifikát (nebo nainstaluj mkcert CA).

Nasazení (doporučení)

  • Frontend: Cloudflare Pages (0 USD u malých projektů)
  • Backend: Fly.io / Render / Railway (HTTPS, jednoduchý deploy)
  • DB: Postgres (Supabase/Neon). Přenést migrace (Alembic).

Bezpečnost

  • Žádná tajemství v repu. certs/*.key, certs/*.crt jsou v .gitignore.
  • V produkci používat HTTPS certifikáty z důvěryhodné CA.
  • Pro DB v produkci zapnout přístupová práva a audit logy.
